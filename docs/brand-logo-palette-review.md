# Homelede 新品牌素材适配与配色评估

## 范围与判断

基线：`0bc8b5a`（ucode / r13）。工作分支：`feat/brand-logo-surfaces`。

本轮替换左上展开横标、收缩图标、登录横标及页面说明 toast 小图标；修复 Edge 原生密码显隐眼睛与主题按钮重复。不改四张用户原始 PNG、不修改调色板 token、不切换出厂或设备默认选择、不修改业务配置。不升级 IPK 版本，本轮为用户授权的源码热更新验收，包管理版本仍是 r13。

专业建议：以“光耀蓝”作为后续默认配色首选，“光耀蓝·晨曦”为亮色选项，黑金保留暖色审美备选，峡谷作为个性主题。旧灰蓝默认的视觉深度区分偏弱，正文及按钮文字的静态 token 对比度存在不足；不能仅替换 Logo 就认为默认配色可读性问题已解决。是否改默认或重调旧默认，需用户确认后单独实施。

专业评价：
- 光耀蓝：冷蓝底与暖橙品牌标形成互补，品牌辨识与正文阅读层次最好，符合稳定、科技感的路由系统定位；注意橙色 Logo 只作品牌，不额外赋予警告语义。
- 晨曦：日间长时间管理更清爽；深蓝侧栏提供品牌锚点，不能因主内容浅色而使用深色字标在侧栏上。
- 黑金：与金橙鹰标统一，但品牌和主交互都偏暖，警告需要继续靠图标/文案区分，适合备选而非唯一默认。
- 峡谷：风格完整但暖红背景更具情绪性，与橙标的冷暖区分不如蓝色方案，适合个性皮肤。
- 默认：新标本身清晰，但旧灰蓝背景层级和正文/按钮文字对比度是既有短板；优化应成对调整文字与底色及 hover/focus，而不是简单提亮全部颜色。

本轮重新统计实际 CSS：app-dark 694 个 hex / 97 个 rgb(a) 字面量；bootstrap-dark 792 / 170；ng.css 223 / 68。app-dark 的 #348cd4 为 116 处，bootstrap-dark 为 38 处。后续改默认须覆盖生成器、基线组件、交互态及应用，不能只改一个 CSS 变量。

## 密码重复眼睛

登录已有唯一 `#login-password-toggle`，footer_login 保持显隐和 reset 状态同步。新增限定登录输入的 `#password::-ms-reveal { display:none }`，抑制 Edge 原生显隐按钮，不禁用自动填充，也不隐藏第三方密码管理器 UI。

独立 headless Edge 实机验证了主题按钮唯一、输入 type 切换、aria-pressed 更新及复位清空并恢复 password。headless 对不支持/不暴露的 UA pseudo computed style 会返回普通元素样式（此环境读到 block），不能用该返回值宣称系统原生眼睛的像素可见性已经断言；用户所用正常有头浏览器中的输入后双眼睛仍应人工复核。未提交任何测试密码。

## 后续决策

本轮品牌适配不等于默认配色体系已经重构。推荐下一步将光耀蓝设置为固件默认，同时保留旧默认供选择；若用户希望延续灰蓝旧默认，应另开完整状态对比度修复，不直接抹平其他配色风格。
